# Contributing

1. Buat branch untuk perubahan.
2. Jangan commit `.env`, database, credential, atau API key.
3. Jalankan pemeriksaan sintaks sebelum commit:

```bash
python -m py_compile server.py
```

4. Pastikan aplikasi dapat dijalankan dengan:

```bash
python server.py
```

5. Buat commit yang menjelaskan perubahan secara singkat.
